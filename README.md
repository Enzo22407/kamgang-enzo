## 🌟 Aperçu & Fonctionnalités

Portfolio interactif haute performance conçu avec une esthétique Cyberpunk / High-Tech Glassmorphism, inspiré des interfaces numériques futuristes et optimisé pour le référencement naturel (SEO) et la vitesse de chargement (100% Core Web Vitals).

### 🚀 Points Forts & Animations
- 🌌 **Arrière-plan Canvas Interactif** : Météores et particules d'aurore connectées en temps réel (60 FPS).
- 🌓 **Mode Sombre 🌙 / Mode Clair ☀️** : Bascule instantanée avec mémorisation des préférences utilisateur (`localStorage`).
- 🌐 **Expérience Bilingue FR 🇫🇷 / EN 🇬🇧** : Traduction dynamique de l'ensemble de l'interface en un clic.
- 🎴 **Perspective 3D Tilt** : Carte de profil interactive réagissant à la physique de la souris.
- 📊 **Projets Phares & Modales Interactives** : Exploration détaillée avec métriques d'impact chiffrées, stacks techniques et filtrage par catégorie (Développement, Growth & Marketing, Community Management).
- 📑 **Accréditations & Certifications** : Inspecteur latéral (Drawer) pour examiner les compétences validées avec codes-barres cybernétiques scannés au survol.
- 📬 **Formulaire de Contact Cyberpunk** : Validation en temps réel et notification de transmission.

## 🚀 Déploiement sur Vercel

1. Rendez-vous sur votre compte [Vercel](https://vercel.com).
2. Cliquez sur **"Add New..."** ➔ **"Project"**.
3. Importez votre dépôt GitHub : `https://github.com/Enzo22407/kamgang-enzo`.
4. Laissez les réglages par défaut (Framework Preset: *Other*) et cliquez sur **Deploy**.
5. Votre site sera disponible en quelques secondes sous `https://kamgang-enzo.vercel.app` !
